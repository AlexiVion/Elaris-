# Elaris — Company Overview

## What Elaris is

Elaris builds a shared data, evidence and coordination layer for Physical AI.

The long-term thesis is that many actors make decisions about the same physical system — integrators, customers, safety teams, procurement, insurers, claims, finance — but the underlying facts are fragmented across tools and organizations.

Elaris does not try to replace those systems. It connects the real deployed configuration to the evidence and decisions that depend on it.

> **Elaris connects the real configuration of a Physical AI system with the evidence and decisions that authorize its deployment, and keeps that relationship valid as the system changes.**

## Shared core

Robot → Configuration → Deployment → Evidence → Requirements → Approvals → Changes → Incidents

Different products and actor views can be built on this shared core.

## First product

**Elaris Deployment Control**

It answers:

1. What is actually deployed?
2. Under which configuration?
3. What evidence and approvals support it?
4. What is missing?
5. What changed?
6. What may need review because of that change?

## First design partner

**Humandroid**

Humandroid is our first real pilot because it sits at the integration/deployment layer, where robot hardware, software, task, environment, customer requirements and operational evidence meet.

## Long-term expansion

Deployment evidence → change management → safety / procurement / customer → insurance → incidents / claims → outcomes → risk intelligence.

This is the direction, not the current MVP scope.
