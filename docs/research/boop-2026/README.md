## Aclaraciones operativas
- Fuentes web de Boop son **declaraciones comerciales o un working draft propio**: no pruebas independientes de disponibilidad de pólizas, licencias, acuerdos de reaseguro, tasa de siniestralidad ni despliegue funcional de RDR.
- Las capacidades de Elaris se comparan con el repositorio conocido a 2026-10-08. Referencia técnica: `docs/portfolio/shared-capabilities.md`, `docs/portfolio/product-catalog.md`, `docs/product/deployment-control`, `docs/product/component-health`.
- No se realizaron nuevas capturas del robot, consultas de datos privados ni ejecuciones de código en el contexto de esta investigación. No hay validación de un suscriptor, broker ni cliente pagador.
- El white paper de Boop es HTML y está disponible en https://www.trustboop.com/research/white-paper; no se debe tratar como norma ISO/PAIDS oficialmente adoptada.
- Se documenta **qué afirmación viene de quién**, no se infiere que un competidor haya implementado sus propuestas sólo porque las publica.
- Los siguientes gates requieren permisos de Humandroid para el caso G1 y acceso autorizado a al menos un expediente real de suscripción para validación sectorial.
