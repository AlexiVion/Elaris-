# Elaris v0.1 — Humandroid Pilot Demo

## Release intent

A demo-ready increment of Elaris Deployment Control aligned to the Humandroid pilot hypothesis.

## Core story

> Know what system is deployed, under which configuration, what evidence and approvals support it, and what deserves review when the system changes.

## Included

- versioned Unitree G1 configuration snapshots;
- immutable deployment baselines;
- deployment/task/environment context;
- evidence and requirements with scope/status/owner/source;
- named approvals;
- before/after configuration diff;
- deterministic Change Impact;
- explicit named re-approval boundaries;
- readiness and evidence coverage;
- incidents linked to deployment state;
- System Passport;
- Deployment Readiness Pack;
- Change Impact Report;
- expiring/revocable Share View;
- audit trail;
- demo-focused baseline and change-impact UX;
- CI covering build + tests + E2E.

## Demo anchor

- `DEP-0017` — Valve Inspection Pilot
- `G1 #017` — Unitree G1
- `B-0017-01 / C004` — active baseline/configuration
- `CHG-0005` — BrainCo Revo2 → Inspire RH56DFX + control-stack update

## Explicit non-claims

This increment does not:
- certify safety;
- declare compliance;
- automatically invalidate approvals;
- provide a risk score;
- provide formal Evidence→Requirement satisfaction traceability;
- replace Humandroid's source systems.

## Next gate

Replace the demo deployment with one real Humandroid deployment and validate:
1. actual configuration inputs;
2. actual evidence and requirements;
3. one real change;
4. one real evidence/requirement relationship;
5. whether Humandroid wants to repeat/pay for the workflow.
