# Risk Intelligence — Version Roadmap

| Version | Scope | Increment | Result | Status | Gate |
|---|:---:|---|---|---|---|
| V0.1 | A | **Governance + outcome schema** | Define outcome/evidence class/reuse-right contracts | `RESEARCH_ONLY` | No cross-customer aggregation without explicit rights. |
| V0.2 | C | **Cohort eligibility engine** | Deterministic comparability/data-quality rules | `BLOCKED_DATA` | Repeated cases exist and exclusions are explicit. |
| V0.3 | C | **Governed outcome dataset** | Multi-case, multi-context, permissioned data | `BLOCKED_DATA` | Sufficient density/labels for intended question. |
| V0.4 | C | **Benchmark Engine** | Descriptive distributions with cohort/provenance metadata | `PROPOSED_AFTER_DATA` | Statistical review confirms defensibility. |
| V0.5 | C | **Intelligence Workbench** | Explore cohorts, assumptions, uncertainty, evidence | `VISION` | Real analyst decision improved. |
| V0.6 | C | **Controlled benchmark delivery** | Audience/purpose/versioned benchmark packs | `VISION` | Reuse rights and disclosure policy approved. |
| V0.7 | C | **Outcome feedback loop** | Products return validated outcomes into governed dataset | `VISION` | Repeated outcome capture operational. |
| V0.8 | C | **Optional predictive research** | Backtesting/calibration/drift/model cards | `RESEARCH_ONLY` | Labels, sample size and independent validation. |
| V0.9 | C | **Model governance** | Versioning, monitoring, disable/review controls | `RESEARCH_ONLY` | A model is actually justified. |
| V1.0 | C | **Paid Risk Intelligence** | Narrow validated data/benchmark product | `VISION` | Paid users + documented dataset rights/value. |
| V2.0 | C | **Cross-domain intelligence** | Only where semantics are proven portable | `RESEARCH_ONLY` | Large, diverse, governed evidence base. |
