# Risk Intelligence

**Product status:** `LONG-TERM DATA FLYWHEEL · DO NOT BUILD NOW`  
**Primary actor:** [A20](../../industry/archetypes/data-risk-intelligence.md)

## Core decision
> Can governed, comparable deployment/evidence/event/outcome data produce reusable benchmarks or models that improve human decisions across Physical AI?

## Triggers
- sufficient repeated outcomes
- benchmark request
- portfolio/reliability research question
- model research

## Evidence today
Long-term thesis only. Current Elaris evidence is too sparse and too concentrated in one G1/component-health field context for defensible cross-market intelligence.

## Shared Elaris truth
Potentially all normalized shared objects plus governed outcomes and evidence-quality metadata.

## Deterministic core
Cohort eligibility, provenance, permissions, normalization, data quality, benchmark computation and leakage prevention.

## AI role
Only after data gates: statistical/ML research, explanation and retrieval. Model outputs stay probabilistic/inferred and never become human authority.

## Human authority
Domain humans interpret results; data owners control reuse; safety/insurance/legal decisions remain with their authorities.

## Horizontal leverage
Every product can create structured facts/outcomes, but only governed reuse and comparable cohorts create an intelligence flywheel.

## Boundaries
Not universal risk score, hidden cross-customer data pool, automated underwriting/safety prediction or model-first product.
