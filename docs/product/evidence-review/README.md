# Evidence Review

**Product status:** `HYPOTHESIS · VISUAL PROTOTYPE`  
**Primary actor:** [A11](../../industry/archetypes/certification-assurance.md)

## Core decision
> What is in assessment scope, what evidence supports it, what findings remain, and what changed since the review?

## Triggers
- assessment request
- new/revised evidence
- finding response
- material change
- reassessment

## Evidence today
Visual prototype and strong reusable evidence/provenance primitives from Component Health. No real independent assessment workflow has been validated.

## Shared Elaris truth
Configuration, Deployment, Evidence, Requirement, Approval, Change, Audit, Share.

## Deterministic core
Scope/version integrity, evidence lineage, completeness/coverage and change-to-scope impact. Sufficiency judgments remain assessor-owned.

## AI role
Document extraction, requirement/evidence linking suggestions, summaries. Never issue certificate/attestation or close findings.

## Human authority
Named assessor/test lab/certification body within its authorization/accreditation.

## Component Health leverage
Component Health contributes source/derivative lineage, quality review and controlled-artifact workbench patterns.

## Boundaries
Not a certification authority, standards database, automatic compliance engine or document repository replacement.

## Product operating model
```text
trigger → exact system/context → evidence/requirements → actor work
→ deterministic/AI assistance → named human decision → versioned output
→ later change/outcome reopens only what is materially affected
```
